# Annex E: Requirements status

This annex points to `REQUIREMENTS.md` at the root of this repository, the table of every requirement on the proof of concept and the paper. The table is edited as work proceeds, so it is not copied here. It states no analytics values; those in the proof of concept are synthetic.

The status column says how far a requirement has come (for example not started, in progress, or done). The check column says what shows it: the file, test, or command that a reader can open or run to confirm the status.
