# Annexes to the technical paper

This folder holds the annexes of the technical paper for the National Research Council of Canada (NRC). The paper is limited to 20 pages and cites these files by URL. Each annex names its source file in the BIM Open Toolkit and the tag it comes from (the coming `v0.2`). Every analytics value in the annexes is synthetic.

- [A: Metric dictionary](A-metric-dictionary.md): every stored metric by level, the run facts, and the `NRC_` naming rule.
- [B: The nine questions](B-questions.md): each question with its expected answer, scoring rule, and the graph that computes it.
- [C: Tool surface](C-tool-surface.md): the tools of the IFC MCP server, grouped, with the four the unattended runs hide.
- [D: The agent's guide](D-agent-guide.md): the skill and guide text the language model is given, unchanged.
- [E: Requirements status](E-requirements-status.md): where the requirements table is and what its columns mean.
- [F: Licences](F-licences.md): third-party material and the licence of each part.
